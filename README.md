# Oasis Infobyte Data Science Internship

This repository contains the Machine Learning projects completed during my Oasis Infobyte Data Science Internship.

## Projects

### 1. Iris Flower Classification
- Built a classification model to predict Iris flower species.
- Algorithms Used:
  - Logistic Regression
  - K-Nearest Neighbors (KNN)

### 2. Sales Prediction using Machine Learning
- Predicted product sales using advertising data.
- Algorithms Used:
  - Linear Regression
  - Random Forest Regressor

### 3. Email Spam Detection using Machine Learning
- Classified messages as Spam or Ham using Natural Language Processing (NLP).
- Algorithms Used:
  - Multinomial Naive Bayes
  - Logistic Regression
  - TF-IDF Vectorizer
